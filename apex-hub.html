1
ActiveCampaign environment variables — blocks ALL lead capture
Go to app.netlify.com → your site → Site configuration → Environment variables. Add:
AC_BASE_URL = your ActiveCampaign API URL (AC Settings → Developer → API Access URL)
AC_API_KEY = from AC Settings → Developer → copy API key
OWNER_EMAIL = your email address
Then: Deploys → Trigger deploy → Deploy site.
CRITICAL
2
AC tags not created — blocks all lead tagging and automation
Go to ActiveCampaign → Lists → Tags → Create tag for each:
SS-NEW   SS-WARM   SS-HOT   SS-APPLIED   SS-CONVERTED   SS-DISTRIBUTOR
