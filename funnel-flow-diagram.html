API CALL REFERENCE
POST /api/subscribe
Creates contact in AC, adds to main list, adds SS-NEW tag, triggers Welcome Sequence automation. Body: { email, name }.
POST /api/score
Scores lead on capital, timeline, commitment, background. Returns { score, tier }. Runs in browser — no server call.
POST /api/apply
Stores application, runs scoring, assigns HOT/WARM/COLD tag in AC, triggers appropriate automation, notifies owner by email. Body: full application payload.
POST /api/webhook
Receives AC webhooks for automation events (contact converted, tag added). Validates HMAC signature from WEBHOOK_SECRET env var. Used for real-time dashboard updates.
