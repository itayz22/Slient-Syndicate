Tech Stack Guide

Every service powering the Silent Syndicate funnel. What each tool does, why it's in the stack, and what it costs. All chosen for automation-first, low-maintenance operation.

HOSTING & DELIVERY
Netlify
Static site hosting and serverless functions. Handles all HTML pages, CSS, JS, and the four API functions (subscribe, apply, score, webhook). Free tier covers the full funnel easily. Deploy via GitHub push.
Free tier
Netlify Functions
Serverless Node.js endpoints. The funnel uses four: /subscribe, /apply, /score, /webhook. Each runs in isolation with a 10-second timeout. 125k invocations/month free.
Included
Custom Domain + SSL
Any registrar works (Namecheap, Cloudflare, GoDaddy). Point DNS to Netlify. Free Let's Encrypt SSL provisioned automatically. Forces HTTPS via _redirects file.
~$12/yr
EMAIL AUTOMATION
ActiveCampaign
CRM and email automation backbone. Stores all contacts, manages tag-based routing, and runs the three automation sequences (Welcome, HOT, Warm). REST API used by all four Netlify functions. Lite plan ($29/mo) covers up to 1,000 contacts.
$29–79/mo
AC Automations
Three automations handle the full lead lifecycle: SS Welcome Sequence (7-day nurture), SS HOT Lead Routing (immediate high-intent path), SS Warm Nurture (30-day slow burn). Triggered by tags added via the API.
Included
AI & CHATBOT
Chatbot Engine
Rule-based chatbot in js/chatbot.js. Pattern-matches user messages against a keyword library and returns structured responses. Runs fully client-side — no API calls, no latency, no cost. Handles objections, qualification questions, and CTA routing.
Free (client-side)
Score Engine
The /score Netlify function scores each applicant on capital, timeline, commitment, and background. Returns HOT (≥70), WARM (40–69), or COLD (<40) with a numeric score. Drives AC tag assignment and funnel routing.
Included
ANALYTICS (OPTIONAL)
Netlify Analytics
Server-side analytics. No tracking scripts, no GDPR cookie banner required. Shows pageviews, unique visitors, top pages, and bandwidth. Optional add-on on Netlify.
$9/mo
Plausible (alternative)
Privacy-first analytics alternative to Google Analytics. Self-hostable or hosted. Lightweight script (under 1KB). Tracks goals, referrers, and conversions without cookies.
$9/mo
TOTAL MONTHLY COST
Minimum viable stack: $29/month (ActiveCampaign Lite only). Full stack with analytics: ~$38–50/month. Domain renewal adds ~$1/month amortised. One Launcher commission ($4,300) covers 12+ months of infrastructure.
